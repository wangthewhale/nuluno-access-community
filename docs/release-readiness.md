# Account Hub candidate preparation

This source addon is not a published alpha.2 release or a deployed cloud service. Build and test this exact source, install its npm tarball into a clean project, and run the included portable-hub consumer check. Maintainers separately review its package inventory, source/pack hashes, own execution receipt and browser acceptance before publishing. No command here creates a GitHub release, npm publication or deployment. Old alpha.1/alpha.2 receipts are not reused as this candidate's proof. The candidate master-key module and Swift source are Apache-2.0; generated platform helpers/manifests are local build outputs.
